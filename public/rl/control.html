Official Stats API: no BakkesMod needed. Scores, boost, stats, spectated player and goal events work. Rocket League does not stream car positions, so the minimap places each car where it last touched the ball or picked up boost (boost pickups need spectator mode) — less smooth than SOS. Turn it on in <Rocket League folder>\TAGame\Config\DefaultStatsAPI.ini (or TAStatsAPI.ini) → [TAGame.MatchStatsExporter_TA]: PacketSendRate=30 and WebPort=49125 (49124, the default, is taken by the RocketLink voice-chat plugin), then restart the game. Spectate a match for full data. Address: ws://localhost:49125, or the TCP port tcp://localhost:49123.
Relay: the game runs on another PC. Type the address of the game data there, e.g. ws://192.168.1.30:49122 (SOS) or ws://192.168.1.30:49125 (official API). SOS and the official API only listen on that PC itself; run RFP Manager there too and use its ws://<that PC>:8080/rl/ws, or any relay that passes the messages on. SOS and official messages are both understood.
