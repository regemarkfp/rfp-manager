Blue Slate Cricket – a cricket theme for RFP Manager
====================================================

What is in it
  scorebug.html     score bug
  lowerthird.html   every lower third (player, batters, bowler, umpires, commentators, toss, result …)
  fullframe.html    every full screen (batting and bowling cards, match summary, squads, match intro,
                    fall of wickets, partnerships, officials, worm and manhattan)
  art/              your bar artwork: bug.png (score bug), lt-a.png (blue over charcoal) and lt-b.png (charcoal over blue).
                    The score bug and lower thirds are drawn on these. Replace a PNG (1920x1080, transparent, same
                    positions) to change the look; move the text boxes in the <style> block of the template if needed.
  theme.css         the look of the full screens. The colours are the first lines of this file.

How to use it
  1. Copy this whole folder into the CasparCG template folder (next to the "rfp" folder).
  2. RFP Manager → Templates → Themes → "Load as theme" next to blue-slate-cricket.
  3. Set the theme on the competition (Competitions → Theme), or choose it in Graphics control → Production.
  The normal cricket buttons then play these templates. Nothing has to be linked by hand: the files have
  the same names and take the same values as the built-in ones.

Try one in a browser:  scorebug.html?demo   lowerthird.html?demo   fullframe.html?demo
